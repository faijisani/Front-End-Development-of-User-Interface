## Project Description
This project is a responsive front-end prototype for an E-Governance Digital Services Portal.

The portal provides a simple interface through which citizens can:

- View government services
- Search for services
- Submit applications
- Track application status
- Login to the citizen portal

## Technology Stack

- HTML5
- CSS3
- JavaScript
- React.js
- React Router
- Fetch API
- Git and GitHub

## Main Features

1. Responsive user interface
2. Service search
3. Government service cards
4. Application form
5. Application status tracker
6. Citizen login interface
7. Planned backend API integration

## Project Structure

src/

## Backend Integration

The project contains an API service layer for future integration with a backend system.

Example endpoints:

GET /api/services

POST /api/applications

GET /api/applications/:id/status
